# 🚀 Angular Docker Application

A Dockerized Angular application demonstrating containerization using Docker and Docker Compose. This project was developed as part of a Cloud Computing coursework assignment to understand container-based application deployment.

---

## 📌 Features

- Angular Frontend
- Dockerized Application
- Docker Compose Support
- Nginx Production Server
- Easy Deployment
- Production Ready Build

---

## 🛠 Technologies

- Angular
- TypeScript
- Docker
- Docker Compose
- Nginx

---

## 🚀 Run

### Build

```bash
docker-compose build
```

### Start

```bash
docker-compose up
```

Application

```
http://localhost:80
```

---

## Docker Commands

Stop

```bash
docker-compose down
```

Rebuild

```bash
docker-compose up --build
```
